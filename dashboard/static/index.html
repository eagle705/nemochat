호스트 스팬 시간은 GPU 커널 시간이 아닙니다. trace / span 식별자를 보존합니다.

가져온 선택 프로세스 범위의 커널 집계입니다. 실행 중첩 가능성이 있으며 커널 이름만으로 소스나 병목을 추론하지 않습니다.

원래 연산·역할·소스 식별자만 표시합니다. 원시 커널을 이름 변경하거나 상관관계를 추정하지 않습니다.

단계별 최적화 검토

관측 증거와 후보 가설을 구분합니다. 일반 권고는 측정 결과가 아니며, 채택 전 동일 워크로드의 정확성·비프로파일 전체 업데이트 A/B 검증이 필요합니다.
